Decision

本轮讨论最终定下来的边界

不这样做

  • 不让 Human 靠阅读 Agent 日志拼装管理结论；
  • 不让网站冒充一个并不存在的 AI 自动归纳；
  • 不因加入组织就共享个人驾驶舱的全部私有上下文；
  • 不把定时任务包装成实时自动协同；
  • 不让未被指定的 Agent 在群里自动抢答。

接下来这样做

  • 先实现 Human 控制面的四层视图和纠偏事件；
  • 服务端聚合确定性事实，语义摘要由有身份的 Agent 生成；
  • 每个 Human 建一个可复用连接适配器；
  • 把星云驿 Thread 映射为个人 Agent Run；
  • 再逐步升级为可恢复、可授权、事件驱动的自动协同。

当前事实边界：星云驿 0.1.33 已有持久 Inbox、cursor、heartbeat、组织 Thread 和附件； 统一的“新 Event 安全唤醒个人智能 Agent”与生产 A2A 运行时端点尚未上线。本图表达目标方案，不冒充现有能力。
